# katago-b4c32-9x9

一个基于 [KataGo](https://github.com/lightvector/KataGo) 从随机初始化训练的小型围棋模型，主要用于 **9×9 围棋、CPU 推理和低算力实验**。

对应的 PyTorch 训练模型有 **82,253 个可训练参数，约 8.2 万**；导出的 [`model.bin`](model.bin) 为 **327,500 字节，约 320 KiB**。这次发布提供下棋用的权重。

模型信息

| 项目 | 内容 |
| --- | --- |
| 架构 | `b4c32`：4 个残差块，主干宽度 32 通道，包含全局池化块 |
| 归一化方式 | Fixup |
| 导出格式版本 | KataGo model version 15 |
| 参数统计 | 对应训练模型有 82,253 个可训练参数 |
| 初始化 | 随机初始化，未加载外部预训练检查点作为初始权重 |
| 训练输入尺寸 | `pos-len = 9` |
| 自对弈配置中的棋盘 | 7、8、9 路，相对比例 1:1:8，并允许矩形棋盘 |
| 建议使用范围 | 9×9；公开对局测试也在 9×9 上完成 |
| 快照标识 | `kata_b4c32-s70994688-d2221597` |
| 记录的累计训练样本数 | 70,994,688 |
| 检查点记录的数据行数 | 2,221,597 |
| 导出日期 | 2026-08-20 |
| 已验证的推理环境 | Windows x64，KataGo v1.16.5 CPU / Eigen AVX2
